# Quince – Ресторан авторской кухни

## Описание
Веб-сайт ресторана с возможностью просмотра меню, добавления блюд в корзину, оформления заказа с доставкой, оставления отзывов.

## Технологии
- Python 3.12, Django 5.0
- SQLite (разработка), в продакшене PostgreSQL
- HTML, Bootstrap, CSS, JavaScript

## Установка и запуск
1. Клонировать репозиторий
2. Создать виртуальное окружение и активировать
3. Установить зависимости: `pip install -r requirements.txt`
4. Создать файл `.env` с переменными окружения (см. `.env.example`)
5. Выполнить миграции: `python manage.py migrate`
6. Создать суперпользователя: `python manage.py createsuperuser`
7. Запустить сервер: `python manage.py runserver`

## Функциональность
- Регистрация и аутентификация
- Просмотр меню с категориями, поиск, фильтрация
- Корзина, оформление заказа с расчётом доставки (доставка по ЖК, вне ЖК, самовывоз)
- История заказов
- Отзывы с модерацией
- Админ-панель для модератора

## SEO и безопасность
- Мета-теги, robots.txt, sitemap.xml
- Вынос секретов в .env
- Заголовки безопасности (XSS, X-Frame-Options, Content-Type)

# Руководство пользователя – Quince

## Регистрация и вход
- Нажмите «Регистрация», заполните поля (имя, email, телефон, пароль).
- После регистрации вы войдёте автоматически. В дальнейшем используйте «Войти».

## Просмотр меню
- На главной странице – популярные блюда.
- Перейдите в «Меню» – увидите все блюда, можно фильтровать по категориям.
- Используйте поиск для поиска блюда по названию.

## Добавление в корзину
- На странице меню нажмите «В корзину» под блюдом (требуется авторизация).
- В корзине можно изменить количество или удалить блюдо.

## Оформление заказа
- Перейдите в корзину → «Оформить заказ».
- Выберите способ получения: самовывоз, доставка по ЖК, доставка за пределы ЖК.
- Заполните адрес и телефон. Стоимость доставки рассчитается автоматически.
- Подтвердите заказ – он появится в истории заказов.

## Мои заказы
- В разделе «Мои заказы» вы видите все заказы с датой, статусом и суммой.
- Если заказ только что создан, его нельзя отменить самостоятельно (обратитесь к менеджеру по телефону).

## Отзывы
- Перейдите в раздел «Отзыв», оставьте оценку (1–5) и текст. Отзыв будет опубликован после модерации.
